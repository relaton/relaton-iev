= DEPRECATION NOTICE

This gem is deprecated and no longer maintained. The code now lives in
the *relaton monogem* — https://github.com/relaton/relaton[relaton/relaton]
(RubyGems: https://rubygems.org/gems/relaton[`relaton`] >= 3.0) — which
bundles every former `relaton-*` flavor gem. This repository is archived
and read-only; issues and pull requests are disabled.

== How to do what this gem did, with `relaton`

Install once:

[source,ruby]
----
# Gemfile
gem "relaton", "~> 3.0"
----

Fetch bibliographic data — one entry point routes to the right dataset
automatically; you never pick a flavor:

[source,ruby]
----
require "relaton"

db = Relaton::Db.new(nil, nil)          # (global_cache, local_cache)

item = db.fetch("ISO 8601-1", "2019")
# [relaton-iso] INFO: (ISO 8601-1:2019) Found: `ISO 8601-1:2019`
item.docidentifier.first.content   # => "ISO 8601-1:2019"

db.fetch("IEC 60050-112:2020")     # => routed to the IEC dataset
db.fetch("ITU-T G.711")            # => routed to the ITU dataset
db.fetch("JIS Z 8301:2019")        # => routed to the JIS dataset
----

The router recognises every former flavor (ISO, IEC, IEEE, ITU, IETF,
BIPM, NIST, OGC, W3C, IHO, JIS, GB, UN, CEN, ETSI, 3GPP, OASIS,
Calconnect, CCSDS, CIE, ECMA, DOI, ISBN, IANA, XSF, Plateau, OIML and
the rest) — all registered automatically.

Transform what you fetched — every fetched item serializes:

[source,ruby]
----
item.to_xml   # => "<bibitem id=\"ISO860112019\" type=\"standard\" …>"
item.to_yaml  # => the YAML rendering of the item
----

Render citations in your citation style (ISO 690 and its variants —
author-date, APA, MLA, Chicago, LNCS, IEEE-SA, JIS en/ja) via
`relaton-render`, which ships in the monogem's ecosystem:

[source,ruby]
----
require "relaton/render"

r = Relaton::Render::General.new(language: "en", style: "author-date")
r.render(item, embedded: true)
# => "INTERNATIONAL ORGANIZATION FOR STANDARDIZATION (ISO). <em>Date and time …</em>"

Relaton::Render::General.new(language: "en", style: "mla")
  .render(item, embedded: true)   # => the MLA form
----

Shipped styles: author-date (ISO 690), apa, chicago, mla, lncs, ieee-sa,
jis-en, jis-ja. Whole-references rendering: `r.render_all(bib, type:
"author-date")`.

Your existing `Relaton::Iso::Bibliography`, `Relaton::Iec::*`,
`Relaton::Db`, `Relaton::Bib::*` calls resolve exactly as before — the
flavors moved into the monogem under the same paths. Per-flavor VERSION
constants are gone; use `Relaton::VERSION`. Any `relaton-* ~> 1.x/2.x`
pin becomes `relaton ~> 3.0` — the monogem is the only line receiving
updates. `relaton-bib` and `relaton-cli` remain separate, maintained
gems.

Metanorma references IEV as a single source, IEC 60050. In reality, IEC 60050 is dozens of separate documents, each with their own part number (corresponding to the starting number of the clause reference; so IEV clause 101-2-3 is actually IEC 60050-101 clause 101-2-3.) This gem helps rewrite the single IEV reference in a Metanorma document, out into all the references it actually corresponds to in the given document. It does so by parsing all first-level clauses in citations to IEV, replacing each by a reference to the IEC 60050 part corresponding to that clause, then looking up each of the IEC 60050 part documents using `relaton-iec`, and inserting those references into the XML document.

== Installation

Add this line to your application's Gemfile:

[source,ruby]
----
gem 'relaton-iev'
----

And then execute:

    $ bundle

Or install it yourself as:

    $ gem install relaton-iev

== Development

After checking out the repo, run `bin/setup` to install dependencies. Then, run `rake spec` to run the tests. You can also run `bin/console` for an interactive prompt that will allow you to experiment.

To install this gem onto your local machine, run `bundle exec rake install`. To release a new version, update the version number in `version.rb`, and then run `bundle exec rake release`, which will create a git tag for the version, push git commits and tags, and push the `.gem` file to [rubygems.org](https://rubygems.org).
